## 1. 这个项目在做什么

给模型一张图片，它判断这是下面 8 类中的哪一类：

**比格、中华田园犬、泰迪、萨摩耶、边牧、金毛、柯基、橘猫**

其中「橘猫」不是狗，是故意加进去的**干扰类**，用来测试模型会不会把橘色的猫误判成狗。

整个项目分四步：

```
① 下载图片 → ② 划分训练/测试集 → ③ 训练模型 → ④ 图形界面预测
```

另外还有一个可选的第五步：**知识蒸馏**（让一个“学生模型”向“教师模型”学习）。

### 1.1 先认识 6 个词

| 词 | 大白话 |
|---|---|
| 训练集 | 平时练习题，模型用来学习 |
| 测试集 | 期末考试题，模型没见过，用来检查真实水平 |
| 模型 | 从图片里找规律、然后做判断的“程序” |
| CNN | 一种专门看图片的神经网络，本项目用的就是它 |
| 置信度 | 模型给自己的答案打的分，高不代表一定对 |
| 知识蒸馏 | 让一个学生模型模仿教师模型的答案 |

## 3. 每个目录/文件在做什么

### 3.1 四个基础脚本

| 文件 | 一句话作用 | 运行后产生什么 |
|---|---|---|
| `1.download_data.py` | 从百度图片下载 8 类图片 | `dog_images/` |
| `2.split_data.py` | 把图片按 8:2 分成训练集和测试集 | `dog_images_split/` |
| `3.train_cnn.py` | 训练教师模型 | `models/dog_classification_model.pth`、`results/` 里的曲线 |
| `4.classifier_ui.py` | 打开图形界面，选图并预测 | 不产生文件，只显示窗口 |

**`1.download_data.py`**

按 8 个关键词去百度图片搜索并下载。每类目标 300 张，已经下载够的类别会自动跳过。
图片保存在 `dog_images/<类别>/`，文件名类似 `比格_1.jpg`。

**`2.split_data.py`**

把 `dog_images/` 里的图片复制一份，按 8:2 分到：

- `dog_images_split/train/`：每类 240 张，用来训练
- `dog_images_split/test/`：每类 60 张，用来考试

每次运行都会先清空旧的划分结果，再重新复制。

**`3.train_cnn.py`**

用训练集训练 8 类 CNN，用测试集评估，最后保存模型。
CPU 上大约需要 **24 分钟**。
训练结束后会生成训练曲线和一张预测示意图。

**`4.classifier_ui.py`**

打开 Tkinter 图形界面：

- 正常模式：先登录，再选图预测
- `--demo`：跳过登录，自动载入 `images/比格.jpg`
- `--model`：指定加载哪个模型（教师或学生）
- `--temperature`：调整显示置信度（默认 0.7，只影响显示）

### 3.2 可选脚本：`6.distillation_cnn.py`

这是**知识蒸馏**脚本，可以不运行。

它做一件事：让一个“学生模型”模仿已经训练好的“教师模型”。

- 教师：`models/dog_classification_model.pth`
- 学生：训练后保存为 `models/distilled_dog_model.pth`

运行后还会生成：

- `results/distillation_history.png`
- `results/distillation_result.txt`

CPU 上大约需要 **28 分钟**。

## 6. 哪些能删、删了怎么恢复

| 路径 | 能删吗 | 删了会怎样 | 怎么恢复 |
|---|---|---|---|
| `dog_images/` | ⚠️ 不建议 | 原始图片没了 | 重新爬取 |
| `dog_images_split/` | ✅ 可以 | 训练没有数据 | `python 2.split_data.py` |
| `images/` | ⚠️ 不建议 | `--demo` 找不到图 | 从测试集重新挑 8 张 |
| `models/` | ✅ 可以 | 界面无法预测 | 重新训练 |
| `results/` | ✅ 可以 | 丢失实验记录 | 重训可恢复部分 |
| `logs/` | ✅ 可以 | 丢失日志 | 重新运行并重定向 |
| `tools/` | ✅ 可以 | 失去截图脚本 | 不影响主流程 |
| `__pycache__/` | ✅ 可以 | 无影响 | Python 自动重建 |

**三条安全规则：**

1. 在 `dog_recognition/` 目录下运行所有命令。
2. 不要改 `dog_images/` 和 `dog_images_split/` 里的类别文件夹名。
3. `models/` 是程序输入，`results/` 只是给人看的；删 `results/` 不影响预测。

## 7. 常见问题

### Q1：为什么有两个数据文件夹？

`dog_images/` 是原始图片，`dog_images_split/` 是复制出来、分好训练/测试的版本。
原始图片永远保留，方便以后重新划分。

### Q2：为什么有两个模型？

- 教师模型：`3.train_cnn.py` 正常训练出来的。
- 学生模型：`6.distillation_cnn.py` 让小学生模仿教师训练出来的。

默认用教师；想用学生就加 `--model models/distilled_dog_model.pth`。

### Q3：为什么界面演示置信度很高，准确率却只有 57.5%？

`images/` 里是挑选过的、模型能认对的 8 张图。整体测试集有 480 张，包含很多难图和噪声图，所以整体准确率只有 57.50%。

另外界面默认用 `T=0.7` 让显示置信度更直观，这**只影响显示，不影响准确率**。想恢复原始显示：

```powershell
python 4.classifier_ui.py --temperature 1.0
```

### Q4：为什么不能改类别文件夹名？

模型保存时会把类别顺序一起存下来。文件夹名改了，训练和预测的类别就对不上，会出现“明明是比格却显示泰迪”。

### Q5：为什么必须在 `dog_recognition/` 目录下运行？

脚本用的是相对路径，比如 `./dog_images`、`./models`。换到别的目录运行会找不到文件。

### Q6：训练要多久？

- 教师模型：CPU 约 24 分钟
- 学生模型：CPU 约 28 分钟

有 NVIDIA 显卡会自动用 GPU，会快很多。

### Q7：提示“未找到模型文件”怎么办？

先训练教师模型：

```powershell
python 3.train_cnn.py
```

### Q8：`__pycache__/` 是什么？

Python 自动生成的缓存，可以随时删，下次运行会自动重建。

## 8. 最后记住三件事

1. **数据流**：`dog_images → dog_images_split → models → 界面`，缺一环就跑不通。
2. **演示图不是训练数据**：`images/` 只用于界面演示，训练用 `dog_images_split/train/`。
3. **结果和日志只是记录**：`results/`、`logs/` 删了不影响程序，但会丢失实验证据。

需要看代码实现时，去看 [README.md](README.md)；本文档只负责帮你快速搞清楚目录和运行方式。
